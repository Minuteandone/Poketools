Supported previews: TGA and BMP artwork, PNG/JPEG, WAV audio, Nintendo DS NCGR graphics when a matching NCLR palette exists, and text data including GMM dialogue and MEV field events. Models and some proprietary formats show metadata and source links instead. Large files load only when selected.

What's worth searching for? 🔎

The index includes every top-level folder, not just a hand-picked list. Some especially interesting places: demo3d (cutscenes and camera data), fldmapdata (overworld maps and events), debug and test_graphic (development assets), op_demo (opening images), message (Japanese dialogue), musical, sound, and zukan_data_old (older Pokédex resources).

The timeline shows commits affecting the selected file, not unrelated changes in the directory. Popular files have precomputed revision histories; for other files, the browser may make one limited GitHub API request. Historical commit dates reflect repository timestamps and aren't guaranteed to be original asset creation dates.
